# Pipeline News release naming

New release folders, release IDs and manifest filenames use `YYYYMMDDHHmm-pipelinenews`.

The digits use the Europe/London operator-inception clock. Every manifest records the full ISO-8601 timestamp and UTC offset.

`pipelinenews` is the permanent lowercase path slug. The visible product title remains `Pipeline News`. Historical uppercase release paths remain immutable and are not renamed. Repository governance files such as `README.md`, `CHANGELOG.md` and `RELEASE_ARCHITECTURE.md` retain their established conventional names.
