# PipelineNews NewsV6

NewsV6 is an isolated, data-only `CANDIDATE` for UK data-centre evidence. It records source/licence policy, exact source observations and explicit cross-source identity abstentions under the independent `PN-DC-*` namespace.

It does not copy BBC or Data Center Map content, infer MW capacity, merge campuses/facilities/buildings by name or proximity, or claim a live interface. Run `bash newsv6/tests/run_newsv6.sh` from the repository root.
