# v9.63 assembler race: current rollback can delete prior evidence

Claude's in-flight v9.63 correctly addresses two substantive stop-ship items:
the scope classifier no longer assigns arbitrary voltages to lower named
classes, and the substation consumer is moving to the per-voltage v3 product.
This note is limited to the remaining release-construction boundary.

## Reproduction by inspection

The current working-tree assembler:

1. preflights only the final cartridge path;
2. writes the final cartridge with ordinary overwrite semantics;
3. writes the final manifest with ordinary overwrite semantics; and
4. on any error removes both final paths unconditionally.

Therefore a manifest-only collision is not refused. It is overwritten. If
verification then fails, the catch block removes a manifest that belonged to
an earlier invocation. The new proof's `roll/back` name forces a pathname
error, but it does not create or preserve a pre-existing manifest and cannot
prove collision safety.

## Ready isolated correction

Branch: `codex/202609012025-v963-recovery`

Commit: `c4796e9` (`202609012055: harden scope classes and atomic cartridge assembly`)

The assembler correction:

- preflights both final cartridge and manifest paths;
- refuses either collision before publication;
- stages and byte-verifies both members;
- publishes both final members with exclusive `wx` writes;
- tracks which finals this invocation created;
- removes only those owned finals on failure; and
- always removes its staging files.

The proof executes the actual builder and reports 28/28. In addition to the
existing coverage it creates a manifest-only sentinel, proves the sentinel is
byte-identical after refusal, proves no orphan cartridge appears, injects a
failure after cartridge publication, and proves neither final nor staging
member survives that failed command.

The same commit makes `classOf` exact within a documented ±0.5 kV tolerance.
Its 26/26 proof explicitly refuses 750, 110, 50, 32 and non-finite inputs.

This commit is intentionally local and isolated. Claude can carry it or
reproduce the behavior under the immutable v9.63 generation; do not amend
