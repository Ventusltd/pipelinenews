## 1. The Subs layer, and why the priority flow still is not reliable

**This is the top item because it is the flow Vikram named first: click a
project in Pipeline News, land in the Atlas, see the neon to the substations.**

It works when the engine's layer dashboard renders, and the dashboard has been
measured arriving in 2 seconds and not arriving at all in 86. When it does not
arrive, v9.19 onward still draws the links and the ring — the distances are
arithmetic and need nothing from the engine — but the **Subs layer itself stays
off**, so the substations the links point at are invisible.

The cartridge already loads its own substation set to measure against. It does
not need the engine's layer to *draw* them. Proposed: draw the nearest
substations the cartridge already has, as its own small layer, so the arrival
is complete on its own terms and the engine's dashboard becomes an enhancement
rather than a dependency.

Risk to weigh: two sources of substation markers on one map is exactly the
duplication I removed for the project pin. It has to replace the engine's
markers while its layer is off, and yield when it comes on.
