# 202608251528-PipelineNews

This is the first PipelineNews app creation under the `YYYYMMDDHHmm-PipelineNews` convention.

The folder is intentionally lightweight. It contains only the HTML entry point, this explanation and a release pointer. CSS, JavaScript and discovery data are stored once under shared SHA-256 object paths and are pinned by the immutable release manifest. Future timestamped app folders reuse unchanged objects rather than copying them.

Status: `CANDIDATE`. The public NewsV7 interface remains unchanged until peer review and browser validation are complete.
